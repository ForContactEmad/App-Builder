## 📖 نظرة عامة

**APP Builder** منصة عربية تفاعلية تُمكّن المستخدمين من بناء تطبيقاتهم خطوة بخطوة عبر **19 مهمة عملية**، من تحديد الفكرة وتصميم الواجهة إلى الاختبار والتجهيز للنشر.

الموقع مبني بـ **HTML + CSS + JavaScript** خالص — بدون أي إطار عمل أو أدوات بناء.

---

## ✨ المزايا

| الميزة | الوصف |
| :--- | :--- |
| 🎨 **تصميم عصري** | تصميم نظيف مع خط IBM Plex Sans Arabic |
| 🌗 **Dark Mode** | تبديل فوري بين الفاتح والداكن مع حفظ التفضيل |
| 📱 **متجاوب** | يعمل على الجوال والتابلت والحاسوب |
| ⚡ **سريع** | بدون أي مكتبات خارجية |
| 🌐 **RTL** | دعم كامل للعربية |
| 🔍 **SEO** | Open Graph + Meta Tags |
| 📄 **19 مهمة** | مقسمة على 4 مراحل |
